Пән туралы мағлұмат

Оқытушы: PhD, аға оқытушы Найзағараева Ақгүл Аманжолқызы

Оқу орны: «С. Сейфуллин атындағы Қазақ агротехникалық зерттеу университеті» КЕАҚ

Мақсаты: Web-технологиялар негіздері, клиент-серверлік архитектура, статистикалық және динамикалық web-сайттар, HTML5, CSS3, JavaScript және PHP тілдерін меңгеру.

Дәріс сабақтары (15 сағат)

1-апта

Дәріс №1: Web технологиялар негіздері. Web стандарттары және олардың дамуы

Желі түсінігі, клиент-сервер архитектурасы, TCP/IP протоколдары, провайдерлер иерархиясы.

2-апта

Дәріс №2: Интернет коммуникациясының моделі. Pull- және Push-моделі

Интерактивтілік, гипермәтін, мультимедиа, «болу эффектісі», желілік навигация, сервистердің сипаттамасы.

3-апта

Дәріс №3: Қолданушының Интернетке кіруі. «Соңғы миля» және Модем

Соңғы миля технологиясы, коммутациялы каналдар, модем қызметі, ASCII-кодтауы.

4-апта

Дәріс №4: Интернет жүйесіне қатынасу технологиялары. DSL, ISDN

DSL, ADSL асимметриялық арналары, ISDN цифрлық байланыс желілері және олардың жылдамдығы.

5-апта

Дәріс №5: Интернеттегі Web-серверлер және CGI технологиясы

Web-сервер қызметі, статистикалық және динамикалық беттер, CGI протоколы, скриптер.

6-апта

Дәріс №6: Web-ресурстарды алу және кэштеу. Прокси-сервер

Кэштеу механизмі, прокси-сервер жұмысы, құжаттардың жарамдылық мерзімі, Web-жылдамдатқыштар.

7-апта

Дәріс №7: Интернеттің іздеу технологиялары

Индекстелген каталогтар, іздеу машиналары (роботтар, өрмекшілер), индекс құру, буль операторлары.

8-апта

Дәріс №8: Электрондық пошта. E-mail сервисі мен протоколдары

E-mail жұмыс механизмі, SMTP және POP3/IMAP протоколдары, MIME стандарты, әр түрлі таңбаларды жөнелту.

9-апта

Дәріс №9: Файлдармен алмасу. FTP-сервисі және клиенттері

FTP протоколы, ресурстардың URL адресациясы, FTP клиенттерінің түрлері (консольдік, бағдарламалық).

10-апта

Дәріс №10: Мәліметтерді қорғау. Цифрлық қолтаңба және Криптография

Симметриялық және асимметриялық шифрлау, Хэш-функция, цифрлық қолтаңба механизмі, ақпараттық қауіпсіздік.

11-апта

Дәріс №11: Пайдаланушыларды идентификациялау. Cookies механизмі

Идентификация, аутентификация, HTTP stateless табиғаты, Set-Cookie атрибуттары, Secure/HttpOnly/SameSite.

12-апта

Дәріс №12: HTML тілінің мультимедиялық мүмкіндіктері. Фреймдер мен Формалар

iframe, <audio>, <video>, <img> тегтері, HTML форма компоненттері (input, select), GET/POST әдістері.

13-апта

Дәріс №13: Стильдердің сатылы кестелері (CSS)

CSS синтаксисі, Inline/Internal/External стильдер, CSS Box Model, позициялау (relative, absolute, fixed) және z-index.

14-апта

Дәріс №14: JavaScript тілі

Синтаксис, айнымалылар (let, const), типеу, шарттар, циклдер, функциялар, объектілер, DOM және оқиғалар (events).

15-апта

Дәріс №15: Web-қосымшалар интерфейсі. HTTP хаттамасы. PHP тілі негіздері

HTTP Request/Response, күй кодтары, серверлік бағдарламалау, PHP тілінің синтаксисі, формаларды өңдеу.

Зертханалық сабақтар (30 сағат)

1-апта

Зертханалық жұмыс №1

Тақырыбы: Веб-бағдарламалауға кіріспе. Visual Studio Code орнату.

Тапсырма: VS Code ортасын жүктеу, орнату, баптау және оның негізгі функционалын зерттеу.

2-апта

Зертханалық жұмыс №2

Тақырыбы: HTML құрылымдық блоктары және негізгі тегтер.

Тапсырма: HTML5 семантикалық тегтерін (<header>, <nav>, <section>, <article>, <footer>) қолдана отырып жеке сайт құру.

3-апта

Зертханалық жұмыс №3

Тақырыбы: HTML: Кестелер.

Тапсырма: <table>, <tr>, <th>, <td>, colspan, rowspan атрибуттарын қолдана отырып сабақ кестесін және студенттер тізімін құру.

4-апта

Зертханалық жұмыс №4

Тақырыбы: HTML: Тізімдер.

Тапсырма: Реттелген (<ol>), маркерленген (<ul>) және анықтамалар (<dl>) тізімдерін жасап, стилін өзгерту.

5-апта

Зертханалық жұмыс №5

Тақырыбы: HTML: Формалар, мультимедиа, фреймдер.

Тапсырма: Тіркелу формасын, емхана немесе оқуға түсу формаларын құрастыру (<input>, <select>, <textarea>).

6-апта

Зертханалық жұмыс №6

Тақырыбы: HTML мультимедиялық тегтеріне кіріспе.

Тапсырма: Веб-параққа сурет (<img>), аудио (<audio>), видео (<video>) және YouTube видеоларын (<iframe>) енгізу.

7-апта

Зертханалық жұмыс №7

Тақырыбы: CSS-ке кіріспе.

Тапсырма: Inline, Internal, External CSS тәсілдерін, селекторларды (Class, ID) және CSS Box Model қасиеттерін меңгеру.

8-апта

Зертханалық жұмыс №8

Тақырыбы: CSS позициялау.

Тапсырма: static, relative, absolute, fixed, sticky позициялау түрлерін және z-index қасиетін қолданып макет жасау.

9-апта

Зертханалық жұмыс №9

Тақырыбы: CSS Flexbox және Grid.

Тапсырма: Бір өлшемді (Flexbox) және екі өлшемді (Grid) заманауи макеттер мен торларды құру.

10-апта

Зертханалық жұмыс №10

Тақырыбы: JavaScript-ке кіріспе.

Тапсырма: JS айнымалылары, деректер типтері, математикалық Math объектісі, массивтер мен реттелген жолдарды өңдеу.

11-апта

Зертханалық жұмыс №11

Тақырыбы: JavaScript операторлары, циклдері, функциялары мен объектілері.

Тапсырма: Шартты операторлар (if/else), for/while циклдері, пайдаланушы функциялары және объектілер массивімен жұмыс.

12-апта

Зертханалық жұмыс №12

Тақырыбы: JS тілінде DOM-мен өзара әрекеттесу және манипуляция.

Тапсырма: DOM элементтерін таңдау, createElement, appendChild, addEventListener арқылы динамикалық пікірлер бөлімін жасау.

13-апта

Зертханалық жұмыс №13

Тақырыбы: PHP және веб-сервер: кіріспе және баптау.

Тапсырма: XAMPP серверлік бағдарламасын орнату, Apache серверін баптау және алғашқы .php скриптін іске қосу.

14-апта

Зертханалық жұмыс №14

Тақырыбы: PHP тіліндегі практикалық тапсырмалар.

Тапсырма: PHP операторларын, массивтерін, шарттарын қолдана отырып серверлік логика бағдарламаларын жазу.

15-апта

Зертханалық жұмыс №15

Тақырыбы: PHP және MySQL көмегімен HTML-де тіркелу және кіру формасы.

Тапсырма: XAMPP, PHP және MySQL деректер қорымен байланысатын авторизация мен тіркелу формасын құру.
